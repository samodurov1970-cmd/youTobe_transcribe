# «Второй мозг» для трейдинга — руководство по построению (v2)

Проект `youTobe_transcribe` — набор микросервисов на Go для отслеживания YouTube-каналов, транскрибации через Whisper и построения базы знаний с помощью pgvector и LLM.

> **Важно:** это руководство для людей. Для агента Cline используйте `CLINE_RULES.md`.

---
