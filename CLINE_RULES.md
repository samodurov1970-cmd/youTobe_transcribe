# Правила Cline (youTobe_transcribe)

## ПОДТВЕРЖДЕНИЕ
Начни ответ строкой: **ПРАВИЛА ПРОЧИТАНЫ: [3-5 ключевых пунктов]**

## ЯЗЫК И ОШИБКИ
- Отвечай только на русском.
- Ошибка → СТОП, покажи текст, не придумывай обходные пути.
- Только `execute_sql`. Никаких `execute_command`, `python -c`, PowerShell-кавычек.

## ГЛАВНЫЙ ПРИНЦИП
1. Сначала ищи ответ в **базе знаний** (`knowledge_chunks`).
2. Если в базе нет — отвечай из **общих знаний**, помечай `[не из базы]`.
3. Всегда явно разделяй: что из базы, что из общих знаний.
